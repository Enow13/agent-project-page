Enterprise Knowledge Agent

Built by Pauline Enow

What I built

I built an enterprise knowledge agent in Microsoft Foundry for a fictional company called Contoso. I wrote its instructions and uploaded two company policy documents (IT security and remote work) using File search, so it answers only from those documents. I tested it with six questions, and it answered five correctly with the exact numbers and said it did not know the sixth, which is the behavior I wanted. While testing I hit a token rate limit error and fixed it by adjusting the model deployment.
